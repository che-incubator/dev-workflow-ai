= What is {prod}?

[role="_abstract"]
{prod} is an autonomous AI engineer bot for the link:https://www.eclipse.org/che/[Eclipse Che] ecosystem.
It automates the full contribution loop — from selecting an open issue to delivering a ready-to-merge pull request — across multiple subprojects.

== How it works

The agent follows a linear pipeline for every issue it processes:

----
Open Issue → Analyze → Implement → Review → Fix feedback → Open PR
----

. *Analyze* — the agent reads the issue, maps it to a subproject, identifies affected files, and estimates story points.
. *Implement* — it checks out a clean branch, applies the fix or feature, and runs the project's linter and tests.
. *Review* — an automated code review runs against the local diff *before* the PR is opened. Blocking findings trigger a fix-feedback loop (up to 3 rounds).
. *Open PR* — after a clean review, the agent opens a pull request via the GitHub API with a structured description.

Security and CVE issues always run first. When multiple CVE issues are open, the agent batches them into a single PR.

== Web interface

{prod} ships with a web UI built on link:https://www.patternfly.org/[PatternFly 6] that lets you:

* Monitor active and past runs in real time
* Browse and filter issues from GitHub and Jira sources
* Manage subprojects and their settings
* Configure LLM providers, auto-approve thresholds, and daily autorun schedules

== Technology stack

Backend::
Fastify, LangGraph (agent orchestration), PostgreSQL / PGlite (embedded Postgres in WASM), webpack.

Frontend::
React 18, PatternFly 6, Redux Toolkit, webpack.

LLM providers::
Claude via Vertex AI, Google Gemini, Ollama (local models).
