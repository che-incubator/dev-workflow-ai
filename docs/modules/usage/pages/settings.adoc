= Settings

[role="_abstract"]
The *Settings* page is divided into three sections: Agent Defaults, AI Providers, and Daily Autorun.

== Agent defaults

Global thresholds applied to every run unless overridden per project.

.Agent defaults configuration
image::settings__agent_Defaults.png[Agent defaults — budget, priority, execution mode]

Auto-approve max budget::
Maximum story points the agent will auto-approve without human review (default: 3).

Auto-approve min priority::
Minimum issue priority level for auto-approval. Issues below this threshold require manual approval. Options: `critical`, `major`, `minor`, `trivial`.

Clone directory path::
Base directory where the agent clones subproject repositories (default: `.repos`).

Execution mode::
* *Create Pull Request* — the agent opens a real PR on GitHub (requires `GITHUB_TOKEN`).
* *Dry Run* — the agent writes a `pr-description.md` file to `output/` instead.

== AI providers

Configure and test LLM backends. Click a provider name to set it as the active backend.

.AI providers configuration
image::settings__AI_Providers.png[AI providers — Vertex AI Claude active]

Each provider row shows:

* *Provider* — name and active badge
* *Credential* — whether the required API key or project ID is configured
* *Model* — the model identifier (e.g., `claude-sonnet-4-6@default`)
* *Region / URL* — Vertex AI region or Ollama base URL

Use the *Test selected provider* section to verify the active provider works before saving. Type a prompt and click *Send* to see the model's response.

Click *+ Add provider* to configure a new backend (Vertex AI, Gemini, or Ollama).

== Daily autorun

Automatically pick and run one issue at scheduled times on selected days of the week.

.Daily autorun scheduler
image::settings__Daily_Autorun.png[Daily autorun — enabled with schedule and active days]

Enable the toggle to activate the scheduler, then configure:

Scheduled times (HH:MM)::
Add one or more times. The agent will pick the highest-scoring eligible issue and run the full loop at each scheduled time.

Active days::
Select which days of the week the autorun should fire. By default, Monday through Friday are checked; Saturday and Sunday are off.

Click *Force start now* to trigger an immediate autorun regardless of the schedule or active days.
